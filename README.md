# REDLINE — موقع شركة احترافي

موقع شركة حديث بتصميم أسود/أحمر، تأثيرات 3D، وتكامل كامل مع بوت تيليجرام.

---

```

│   ├── package.json

    └── images/             ← ضع صورك هنا
```

## 🚀 خطوات التشغيل

### 1️⃣ تشغيل الموقع (محلياً)

**الطريقة الأسهل:** افتح `index.html` مباشرة في المتصفح.

**الطريقة الأفضل (مع PHP):**
```bash
# إذا عندك PHP مثبت
cd company-site
php -S localhost:8000
# افتح http://localhost:8000
```

**أو مع XAMPP / WAMP / MAMP:** انسخ المجلد إلى `htdocs` وافتح `http://localhost/company-site/`

> ⚠️ النماذج تحتاج PHP شغّال (لإرسال البيانات لتيليجرام) — عرض الموقع بدون PHP شغّال 100%.

---

### 2️⃣ إعداد بوت تيليجرام

#### أ) أنشئ البوت
1. افتح تيليجرام، ابحث عن `@BotFather`
2. أرسل `/newbot`
3. اختر اسم ومعرّف للبوت (مثل: `redline_company_bot`)
4. **انسخ التوكن** — شكله مثل: `1234567890:ABCdef...`

#### ب) احصل على رقم حسابك (Chat ID)
1. افتح تيليجرام، ابحث عن `@userinfobot`
2. أرسل له أي رسالة
3. **انسخ الـ ID** — شكله مثل: `987654321`

#### ج) هيّئ الـ PHP
افتح `api/send_to_telegram.php` وغيّر:
```php
const TELEGRAM_BOT_TOKEN = 'التوكن_هنا';
const TELEGRAM_CHAT_ID   = 'الـ_ID_هنا';
```

#### د) هيّئ بوت Node.js (اختياري لكنه موصى به)
```bash
cd bot
cp .env.example .env
# افتح .env وضع التوكن والـ Chat ID
npm install
npm start
```

> 💡 البوت الإضافي يضيف: رد سريع على العملاء، تصدير Excel للسجل، إحصائيات.

---

### 3️⃣ تخصيص بيانات الشركة

افتح `config.js` وغيّر:
- اسم الشركة
- الوصف
- الإحصائيات
- روابط التواصل الاجتماعي (واتساب، انستقرام، ...)
- البريد والهاتف

افتح `index.html` وغيّر:
- `<title>` في `<head>`
- نصوص الأقسام المختلفة

---

### 4️⃣ النشر على الإنترنت

**خيارات مجانية/رخيصة:**

| المنصة | المميزات | السعر |
|--------|---------|------|
| **Hostinger** | PHP + SSL + Domain | ~$3/شهر |
| **Vercel** | Static (HTML/CSS/JS فقط، بدون PHP) | مجاني |
| **Netlify** | Static فقط | مجاني |
| **Railway** | PHP/Node | مجاني جزئياً |
| **Render** | PHP/Node | مجاني |

**لو نشرت على Vercel/Netlify (Static):**
- النماذج بتمر بـ Formspree أو Web3Forms (بديل لـ PHP)
- عدّل `js/forms.js` ليكلّم endpoint تلك الخدمة

## 🔧 حل المشاكل

**النماذج لا ترسل؟**
- تأكد إن `api/send_to_telegram.php` يفتح بدون 404
- افتح `Console` (F12) لمشاهدة الخطأ
- تأكد إن التوكن والـ Chat ID صحيحة في `api/send_to_telegram.php`

**البوت لا يستجيب؟**
- تأكد إنك شغّلت `npm start` في مجلد `bot`
- تأكد إن التوكن صحيح في `.env`
- جرّب `/start` في محادثة مع البوت

**التصميم مكسور على الجوال؟**
- افتح DevTools واختر وضع الجوال
- تأكد إنك ما حذفت `viewport` meta tag
